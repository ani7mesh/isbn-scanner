Book Scanner - ISBN Capture

A mobile-first web app for scanning ISBN barcodes and building a book list for library management.

## Features

- 📷 **Camera-based barcode scanning** with fallback support
- 📚 **Multi-source book lookup** (Google Books, Open Library, ISBNdb)
- 💾 **Local storage** - books persist between sessions
- 📋 **Copy ISBNs** individually or in bulk
- 📧 **Email export** - send list to yourself
- 📊 **CSV export** for spreadsheet import
- 🎨 **Dark mode** support
- 📱 **PWA-ready** - install on phone

## Usage

1. Open the app on your phone
2. Click "Start Scanner"
3. Point camera at ISBN barcode
4. Books are automatically added
5. Use export options when done
